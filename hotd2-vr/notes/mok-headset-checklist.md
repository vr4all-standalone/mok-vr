# Physical headset checklist

These checks still require a real headset; desktop simulation does not establish them.

- Fresh install, All files access, file discovery and Play on Quest 3.
- Staff preparation, B/Y skip, second-launch cache reuse and relaunch after Quit.
- Tracking, stereo, depth, near-plane geometry and aiming throughout several stages.
- Solo either-trigger hand transfer; default P1 left/P2 right; alternate layout and both reload modes.
- Controller labels, menu pointers, pause/recenter, focus loss and resume.
- Haptic feel, comfort, sustained frame rate and temperature on each Quest model.
- PC VR on the user's actual OpenXR runtime and controller profile.

The signed test build is installed on the connected Quest 3S, with the user’s game files in Download. Physical play, comfort and aiming validation remain with the user. The generated staff cache was explicitly removed for a fresh-extraction check; bundled controller models, saves and settings were preserved.
